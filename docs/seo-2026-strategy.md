# Strategi Massive SEO 2026 MTsN 2 Kota Kediri

## 1. Executive Summary

Strategi SEO 2026 untuk MTsN 2 Kota Kediri harus menggabungkan technical SEO, AEO, GEO, dan penguatan E-E-A-T agar website resmi madrasah menjadi sumber utama yang dipercaya Google dan answer engines. Fokus utama bukan hanya ranking kata kunci, tetapi memastikan setiap halaman menjawab pertanyaan pengguna secara langsung, terstruktur, dan mudah dikutip oleh AI.

Dalam 3 bulan pertama, target realistis adalah seluruh halaman penting terindeks, sitemap valid, tidak ada error mobile utama, dan CTR meningkat melalui title/description yang lebih spesifik. Dalam 6 bulan, targetnya ranking top 3-10 untuk keyword branded dan lokal seperti "MTsN 2 Kota Kediri", "Madtsanda", "PPDB MTsN 2 Kota Kediri", "madrasah riset Kediri", dan mulai muncul di featured snippet atau People Also Ask untuk query informasional. Dalam 12 bulan, targetnya mendominasi hasil lokal sekolah Islam/madrasah Kediri, mendapatkan citation dari AI untuk profil sekolah, PPDB, program madrasah, riset siswa, dan berita resmi.

KPI utama: pertumbuhan organic clicks 50-100% dalam 6 bulan dari baseline GSC, 80% halaman publik valid mobile-first, 90% artikel berita baru punya metadata dan structured data, 20-30 query masuk top 10 dalam 12 bulan, dan peningkatan share of voice AI untuk query branded/lokal. Semua taktik harus white-hat, berbasis konten asli, data internal madrasah, dan dokumentasi resmi Google: SEO Starter Guide, mobile-first indexing, structured data, Search Console, AI features, dan AI optimization guide.

## 3. Technical SEO & Google Search Console Mastery

Prioritas teknis:
- Pastikan mobile-first: tidak ada horizontal overflow, font terbaca, tombol mudah disentuh, dan Core Web Vitals stabil.
- Gunakan sitemap dinamis untuk halaman statis, berita, dan riset.
- Gunakan robots.txt yang mengizinkan publik dan mengecualikan `/dashboard`.
- Gunakan canonical per halaman agar route query/pagination tidak menciptakan duplikasi.
- Tambahkan structured data: EducationalOrganization, WebSite, BreadcrumbList, NewsArticle, ScholarlyArticle, dan CollectionPage.
- Pastikan gambar memakai alt deskriptif, sizes benar, dan above-the-fold memakai priority/fetchPriority.

Setup GSC:
1. Verifikasi domain property untuk `mtsn2kotakediri.sch.id`.
2. Submit `https://www.mtsn2kotakediri.sch.id/sitemap.xml`.
3. Pantau Pages, Sitemaps, Core Web Vitals, HTTPS, dan Rich Results.
4. Gunakan URL Inspection untuk halaman utama, berita detail, research detail, dan program madrasah.
5. Hubungkan data GSC ke Looker Studio untuk dashboard organic visibility.

Environment placeholders:
- `NEXT_PUBLIC_BASE_URL=https://www.mtsn2kotakediri.sch.id`
- `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION=` diisi setelah GSC property siap.
- `NEXT_PUBLIC_GA_MEASUREMENT_ID=` disiapkan untuk GA4 jika tracking analytics diaktifkan.

Tools yang disarankan: Google Search Console, GA4, Looker Studio, PageSpeed Insights, Rich Results Test, Schema Markup Validator, Ahrefs/Semrush untuk competitor gap, dan crawler ringan seperti Screaming Frog.

## 4. On-Page & Content Optimization (Triple-Threat: SEO + AEO + GEO)

Prinsip halaman:
- Jawab langsung dalam 40-60 kata pertama.
- Gunakan heading berbentuk pertanyaan untuk FAQ dan AEO.
- Buat section self-contained: satu pertanyaan, satu jawaban, data pendukung, link internal.
- Tambahkan mini TOC untuk halaman panjang seperti PPDB, Program Madrasah, dan Profil.
- Gunakan bullet, tabel, list, dan definisi ringkas agar mudah diekstrak AI.

E-E-A-T:
- Tampilkan identitas resmi sekolah, alamat, kontak, logo, dan profil kepala madrasah.
- Berita mencantumkan author/editor dan tanggal update.
- Halaman riset mencantumkan penulis, kategori, status publikasi, abstrak, dan dokumen.
- Update konten penting minimal per semester atau saat informasi berubah.

Content brief standar:
- Target keyword dan intent.
- Jawaban ringkas pertama.
- Struktur H2/H3 berbasis pertanyaan.
- Data internal yang harus muncul.
- Media pendukung dan alt text.
- Link internal ke profil, program, berita, riset, library, dan PPDB.
- Schema yang dipakai.

## 5. Off-Page, Authority & Distribution

Link building etis:
- Profil resmi di Kemenag, direktori pendidikan, dan media lokal.
- Berita prestasi dikirim ke portal lokal dengan link balik ke artikel resmi.
- Kolaborasi riset siswa dengan Madrasah/komunitas edukasi lokal.
- Pastikan NAP konsisten: nama, alamat, telepon.

Distribusi AEO/GEO:
- YouTube: video profil, kegiatan, PPDB, dan riset dengan deskripsi berisi link canonical.
- LinkedIn/Facebook/Instagram: ringkas berita dan arahkan ke halaman resmi.
- Quora/Reddit tidak menjadi prioritas utama untuk sekolah lokal Indonesia, tetapi bisa digunakan untuk jawaban edukatif non-promosional jika ada komunitas relevan.
- Bangun UGC terkurasi: testimoni alumni, karya siswa, prestasi, dokumentasi ekstrakurikuler.

## 6. Measurement, Monitoring & Iteration

KPI:
- Organic clicks, impressions, CTR, average position dari GSC.
- Indexed pages dan sitemap coverage.
- Core Web Vitals mobile.
- Rich result eligibility.
- Query branded vs non-branded.
- AI citation tracking manual bulanan untuk ChatGPT, Gemini, Perplexity, Grok, dan AI Overviews.

Cadence:
- Mingguan: cek error GSC, indexing artikel baru, dan query naik/turun.
- Bulanan: audit CTR, update title/meta yang rendah, cek halaman mobile bermasalah.
- Quarterly: refresh konten profil, program, PPDB, dan FAQ; lakukan competitor gap.

Eksperimen:
- A/B title/meta untuk halaman berita dan PPDB.
- FAQ answer-first vs narasi panjang.
- Struktur tabel untuk program madrasah.
- Internal linking dari berita ke program/ristek/library.
